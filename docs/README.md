## 🛠️ 核心技术栈摘要

| 模块 | 技术选型 |
|---|---|
| **前端** | Vue 3 + Ant Design Vue 4 + Vite + Pinia + hls.js |
| **后端** | FastAPI + SQLModel + Python 3.9+ |
| **AI 推理** | ONNX Runtime (CPU + GPU/CUDA) |
| **配置中心** | Redis (统一配置、服务注册、路径管理) |
| **视频交付** | HLS (Session 录制 + 双 URL 架构) |
| **流媒体网关** | MediaMTX v1.18.1 (RTSP/HLS/WebRTC) |
| **视频采集器** | FFmpegCapture (子进程采集) |
| **数据存储** | SQLite (本地化引擎) |

## 最新更新 (v2.9.0)

- **大文件上传配额倍增 (v2.9.0)**：用户存储空间配额和单文件限制从 1GB 提升至 **20GB**，彻底解决大文件上传卡死问题。
- **历史视频回放状态精准指引 (v2.9.0)**：停止后查看历史回放时，状态 UI 自动切换为"视频回放"。
- **长文本智能截断 (v2.9.0)**：任务名称和描述字段超长时自动省略号截断，hover 显示完整内容。
- **HLS 播放抗卡顿与绝对时钟对齐 (v2.8.0)**：`liveSyncDurationCount` 调优至 `5.5`，`compensationMs` 校准为 `-2500`，彻底消除首屏卡顿与检测记录抢跑。
- **多层性能缓存 (v2.7.0)**：目录大小 30s TTL、m3u8 直播 1s TTL、元数据 5s TTL，API 响应时间降低 99%。
- **服务端帧嵌入渲染恢复 (v2.5.1)**：恢复 `AnnotatedHLSWriter` 服务端渲染，720p@10fps NVENC 编码，检测框帧精确对齐。
- **全新大屏监控看板 (v2.6.0)**：新增多路自适应监控网格，采用 `ResizeObserver` + CSS `transform: scale()` 对播放器进行组件等比微缩渲染。
