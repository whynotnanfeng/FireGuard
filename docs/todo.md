### 双 URL HLS 架构与 Session 录制 (v1.2.5)
- [x] **Session 录制管理**: StorageManager 支持 session-based 录制，每次启动/停止创建独立 session 目录。
- [x] **M3U8 合并**: `generate_merged_m3u8()` 将所有 session 用 `#EXT-X-DISCONTINUITY` 拼接为统一时间轴。
- [x] **VOD 模式**: `force_vod` 参数强制添加 `#EXT-X-ENDLIST`，使 hls.js 支持随机 seek。
- [x] **双 URL 架构**: 直播使用 `/api/storage/{id}/live/index.m3u8`，回放使用 `/api/tasks/{id}/stream.m3u8?mode=vod`。
- [x] **Elapsed-Time 进度条**: 直播模式使用 elapsed time 驱动进度条，始终定位在最右端。
- [x] **liveVideoReady 标志**: HLS 视频首次播放后隐藏加载遮罩。
- [x] **WS running 触发重连**: 后端通知 running 状态时自动恢复 HLS 连接。
- [x] **Task 模型扩展**: 新增 `first_session_start_time`、`session_count` 字段。

### HLS 回放与时钟对齐优化 (v1.2.4)
- [x] **后台流同步**: HLS 引擎后台常驻，进度条与真实视频时长 (`video.duration`) 强绑定。
- [x] **零缓存刷新**: 追加 `?t=timestamp` 解决任务重启后回放内容陈旧的问题。
- [x] **全自动显框**: 通过 Watcher 解决异步数据加载导致的首次回放不显框问题。
- [x] **时间基准重构**: 以第一条记录作为起点，彻底消除进度条“虚假时长”与“闪跳”现象。
- [x] **代码清理**: 移除残留的 `tickerInterval` 变量，删除冗余的 `VideoPlayer.backup.vue`。
