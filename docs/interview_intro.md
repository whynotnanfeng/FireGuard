# 项目面试简介：火灾目标检测 Web 系统

## 1. 项目定位与核心价值
本项目是一个集成了**深度学习推理引擎**与 **Web 实时监控**的综合性火灾目标检测平台。它为工业监控、智慧安防等场景提供了一站式的“模型管理 - 任务下发 - 实时检测 - 结果分析”全流程解决方案。

## 2. 功能架构 (Functional Architecture)
从产品视角看，系统功能由下至上构建，形成了一套完整的检测闭环：
- **用户接入层**：基于 JWT 实现多租户资源隔离与安全认证。
- **任务调度层**：通过异步状态机与单并发队列管理，实现任务的平滑排队与资源保护。
- **AI 推理层**：统一的检测器抽象，解耦 YOLO 与 ONNX 推理逻辑，支持分帧处理策略。
- **可视化层**：利用 WebSocket 实时渲染标注帧，提供离线结果的深度回溯。

## 3. 产品功能模块 (Product Modules)
系统划分为四大核心业务模块，涵盖了从模型到监控的完整链路：
- **模型管理中心**：支持 YOLO/ONNX 模型上传，允许用户动态配置检测环境（RGB/红外）与标签映射（Label Mapping）。
- **任务流水线**：提供向导式任务创建流程，支持图片、离线视频及 RTSP 实时流的多源接入。
- **智能监控看板**：专为流式任务设计的实时预览页面，支持高频图像帧的实时标注与低延迟展示。
- **历史记录与回溯**：完整的任务日志记录，支持检测结果的在线查看、标注回放与数据分析。

## 4. 技术栈与核心实现 (Technical Usage)
- **前端架构**：采用 **Vue 3 (Composition API) + TypeScript + Pinia** 构建，使用 **Element Plus** 实现响应式后台管理系统。
- **后端架构**：基于 **FastAPI** 异步框架，结合 **SQLModel (SQLAlchemy + Pydantic)** 实现了高性能的 RESTful API。
- **推理层实现**：深度集成 **Ultralytics (YOLOv8)** 与 **ONNX Runtime**，支持多硬件加速与动态模型文件路由。
- **实时通信**：通过 **WebSocket** 实现双向数据流传输，优化了视频帧在网络中的传输效率与渲染延迟。
- **数据管理**：使用 **SQLite** 进行轻量级元数据存储，配合物理文件隔离机制，确保了多租户环境下的数据安全性。

## 5. 总结 (Key Highlights)
该项目展现了在**全栈 Web 开发**、**异步并发处理**以及**深度学习模型工程化落地**等方面的综合技术能力。
