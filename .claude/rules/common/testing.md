# 通用测试规范 (General Testing Standards)

## 核心原则
- **优先测试 (TDD)**: 在实现复杂逻辑（如检测算法逻辑、权限校验）前，先编写失败的测试用例。
- **验证循环**: 每次修改后必须运行相关模块的测试套件。
- **覆盖率要求**: 核心业务代码（`backend/app/services`）的测试覆盖率应达到 80% 以上。

## 后端 (FastAPI) 测试要求
- 使用 `pytest` 和 `httpx.AsyncClient` 进行异步接口测试。
- 模拟数据库环境：测试应在独立的 SQLite 内存数据库或临时测试数据库中运行，不得影响开发数据库。
- 夹具 (Fixtures): 常用夹具应定义在 `tests/conftest.py` 中。

## 前端 (Vue 3) 测试要求
- 组件测试：关键交互组件应编写单元测试。
- 类型安全：必须通过 `vue-tsc` 检查，严禁滥用 `any`。

## 成功标准 (Success Criteria)
- 所有测试用例绿色通过。
- 无回归错误。
- 对应的业务逻辑完全符合用户需求描述。
