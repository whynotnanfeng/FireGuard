# 前端组件与设计模式 (Frontend Patterns)

## UI 库规范 (Ant Design Vue)
- **统一样式**: 必须遵循项目的色彩体系和间距标准。
- **表单**: 提交类交互优先使用 `a-form` 组件，并配套校验规则。
- **图标**: 使用 `@ant-design/icons-vue` 提供的矢量图标。

## 组件设计模式
1. **容器组件 (Container)**: 负责处理数据抓取和状态逻辑。
2. **展示组件 (Presentational)**: 纯 UI 组件，只通过 Props 接收数据，不保存业务状态。
3. **复合模式 (Composables)**: 抽离可复用的逻辑（如：视频流重连逻辑、WS 消息监听）。

## 交互准则
- **加载状态 (Loading)**: 长耗时操作（如检测算法启动）必须显示全局或局部的 Loading 状态。
- **反馈 (Feedback)**: 关键操作成功或失败后，必须通过 `message` 或 `notification` 提供明确的用户反馈。
- **响应式布局**: UI 必须适配不同的屏幕分辨率，核心视频预览区域应根据屏幕纵横比自适应。
