设计决策说明 (Design Decisions)

色彩体系 (Color Palette)

采用 Gray-Blue 工业色板，以冷灰中性色为主调，蓝色作为功能强调色。状态色沿用行业标准：绿=正常/完成，红=告警/高置信，橙=警告/运行中。

布局结构 (Layout)

  • 左侧媒体区 flex:1 自适应，黑色背景最大化内容沉浸感
  • 右侧信息面板固定 380px（比 v1 的 340px 更宽松），可滚动
  • 顶部标题栏：任务名称 + 类型徽章 + 状态指示灯 + 操作按钮
  • 底部操作栏：主次按钮分层，危险操作（停止）使用红色警示
  • 信息面板分区：概览统计 → 当前帧类别 → 累计分布 → 事件列表

交互优化 (Interaction)

  • 图像/视频：轮播导航 + 圆点指示器 + 键盘左右切换（← →）
  • 视频流：LIVE 实时标识 + 脉冲动画 + 历史回放切换 + 进度条分段
  • 检测事件：时间倒序 + 分页 + 高置信度红色高亮 + hover 行背景
  • 全屏按钮：一键沉浸，隐藏右侧信息面板
  • 键盘快捷键提示：Space 播放/暂停，F 全屏，Esc 关闭

工业规范对齐 (Standards)

  • 等宽字体 (SF Mono / JetBrains Mono) 显示文件名、时间戳、数值
  • 状态指示灯 + 外发光脉冲动画表示运行中任务
  • 类别分布条形图统一比例，渐变填充增强视觉层次
  • 检测事件时间精确到秒，符合安防监控行业标准
  • 危险操作（停止任务）使用红色警示按钮，防止误操作
v2 核心设计升级
▧

左右分栏优化

右侧面板从 340px 扩展至 380px，信息密度更舒适，分区层次更清晰

◉

统计可视化增强

渐变条形图 + 标签云 + 三列统计卡片，数据对比一目了然

⚡

实时反馈升级

LIVE 标识 + 外发光脉冲状态灯 + 检测事件 hover 高亮 + 高置信红色标记

⛶

全屏沉浸模式

一键全屏隐藏信息面板，专注媒体内容；Esc 退出，符合操作习惯

⇄

多通道切换

RGB / IR 双通道一键切换，支持多模态模型任务，按钮状态即时反馈

⊞

进度分段可视化

绿色标记录制片段，hover 显示缩略图，支持精准 seek 跳转
